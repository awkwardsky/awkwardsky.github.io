# Repository Instructions

## Git Author

All commits created in this repository must use the owner's GitHub identity:

```text
awkwardsky <9321793+awkwardsky@users.noreply.github.com>
```

Do not create commits with any other author or committer identity, including
`haru`, `Haru`, `aiueo`, local machine emails, or personal email addresses.

Before committing, verify:

```bash
git config --get user.name
git config --get user.email
```

Expected output:

```text
awkwardsky
9321793+awkwardsky@users.noreply.github.com
```

## Private Source Handling

Do not copy source code from private local projects into this repository. For
`kagerune-color`, only public showcase media under `web/showcases/` may be used.
